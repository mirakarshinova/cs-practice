Git - программа на компьютере, которая хранит изменения.
GitHub - сайт, где зранится копия репозитория.
использованные команды
git diff показывает изменения которые уже сделали в  файле но не добавили командой  git add
git diff --staged показывает что уже добавлено через git и попадает в следующий коммит
git status показывает текущее состояние репозитория на какой ветке какие файлы изменены
ветка отдельная линия истории уквзвтельна последний коммит
при новом коммите указатель текущей ветки сдвигается веперд остальные ветки не меняются
слияние переносит изменения из одной ветки в другую
